- **MonkiiPad20** — RP2040-Zero, 20 keys on a 4x6 diode matrix. SSD1306 OLED driven over a second I2C bus, two layers (Shortcuter / Typist) you swap by holding FN, and a robot-eye screensaver when it sits idle.
- **MonkiiBoard39** — 39-key board on a Pro Micro (ATmega32U4). 4x10 matrix, sticky modifiers so you tap instead of chord, and a double-tap Windows key.
- **MonkiiPad3x3** — nine keys, 3x3 matrix. Long-press one key to flip the whole pad between a numpad and a macro layer of arrows and edit shortcuts.
- **MonkiiPad20 PCB** — my first real board in KiCad. Two layers, 120 x 86 mm, a diode footprint under every switch and a labelled RP2040-Zero header, all in one clean Gerber pack.
- **Zombie Survival (FPGA)** — Verilog on a Tang Nano 4K, a little survival game running straight on the hardware with physical buttons for input.
